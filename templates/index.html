Spotify Playlist Merger

Configuration

Cette application locale fusionne vos playlists Spotify et peut les transférer vers Apple Music, Deezer ou YouTube Music. Elle utilise OAuth 2.0 avec PKCE pour Spotify : aucun mot de passe Spotify ne transite par cette application, et son code n'a besoin d'aucun secret.

  1. Ouvrez le Spotify Developer Dashboard et connectez-vous. Spotify exige un compte Premium pour les applications en mode développement.
  2. Créez une application (« Create app »). Nom et description libres.
  3. Dans les paramètres, ajoutez cette Redirect URI, exactement :
    http://127.0.0.1:8888/callback
  4. Enregistrez, puis copiez le Client ID et collez-le ci-dessous.

Le Client ID est stocké uniquement en local dans data/config.json.

    Le transfert lit vos playlists Spotify puis recrée la sélection dans Apple Music. Chaque morceau est d'abord recherché par ISRC, puis par titre et artiste.

    Apple Music nécessite un compte Apple Developer Program (MusicKit), une clé privée .p8 et un abonnement Apple Music actif.

    Configuration MusicKit

    La clé est stockée uniquement en local dans data/apple_key.p8 avec des permissions restreintes (0600).

    Configuration enregistrée. Connectez votre compte Apple Music pour autoriser la lecture de votre bibliothèque et la création de playlists.

    YouTube Music n'a pas d'API officielle de gestion des playlists : l'application utilise ytmusicapi avec une autorisation Google OAuth. Cette intégration non officielle peut cesser de fonctionner si Google modifie son service. Les morceaux sont retrouvés par titre, artiste et durée.

    Dans la Google Cloud Console, créez un client OAuth de type « TV et appareils à accès limité » et activez l'API YouTube Data.
